# Ejecución

This folder contains execution evidence for training sessions. Create one subfolder per instructor; each instructor folder will hold the files that document their delivered sessions, such as attendance lists, session reports, photos, videos, slides, exercises, and scored work.

Current instructor folders:

- `javier_pinto/`
- `carlos_fabian_martinez/`

To add more instructors, create a new folder under `ejecucion/` named with the instructor's identifier (e.g., `instructor_3`).
